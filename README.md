# Fieldwork concepts

Three independent interactive concepts built from public project briefs. They have not been commissioned or approved by the organizations named in the briefs. They are not production applications.

- [Daylight Leave](https://curvescope.github.io/leave.html): browser-only sample leave workflow.
- [ContinuumX Readiness](https://curvescope.github.io/readiness.html): illustrative assessment and report.
- [SSLP design concept](https://curvescope.github.io/clinic.html): an independent homepage concept, not the clinic's official website. Its inquiry form only previews a sample message; it sends nothing.

The demos do not transmit form entries to a server. Leave and readiness sample progress stays in the visitor's browser storage. The clinic form sends and saves nothing. Do not enter sensitive information.

## Discuss a project

[Start a project inquiry](https://github.com/CurveScope/CurveScope.github.io/issues/new?title=Project%20inquiry) with the brief, timeline, and budget. GitHub issues are public, so do not include passwords, personal information, or confidential materials. No contract or payment is handled by these demos.
